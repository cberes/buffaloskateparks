## Location

Allegany River Park, 23 W Union St, Allegany, NY 14706

## Description

Small skatepark. Opened in [fall 2024](https://www.wgrz.com/article/entertainment/television/programs/most-buffalo/grand-opening-allegany-river-skate-park/71-38093727-5f98-499c-baba-ccb6bb3701f2).

### Bathrooms

There are bathrooms in the park. If you're lucky, they'll be unlocked.

## Features

- 3' quarter pipe, 4' quarter pipe
- 3' box jump
- hip (with ledge)
- box
- flat rail
- curbs
